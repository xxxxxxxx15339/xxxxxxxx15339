## Featured Projects

### [Shocks-and-WENO](https://github.com/xxxxxxxx15339/Shocks-and-WENO)

**Scientific Machine Learning · Numerical Methods · Python · TensorFlow/Keras**

A structured research-oriented framework for classical and neural shock-capturing methods.

- Implements ENO and WENO3, WENO5 and WENO7 reconstruction methods.
- Supports scalar conservation laws and one-dimensional Euler equations.
- Includes convergence studies and Sod and Shu–Osher numerical benchmarks.
- Evaluates error, conservation, positivity, overshoot and shock localization.
- Contains initial TENO and neural stencil-classification components.
- Extends and restructures an attributed research implementation by Stevens and Colonius.

---

### [GlassBox AutoML Agent](https://github.com/xxxxxxxx15339/GlassBox-AutoML-Agent)

**Machine Learning · AutoML · NumPy · Explainability · Python**

A transparent, NumPy-only AutoML framework implemented without relying on scikit-learn for its core algorithms.

- Implements automated exploratory data analysis and preprocessing.
- Includes classification and regression algorithms developed from first principles.
- Supports K-fold validation, grid search and random hyperparameter search.
- Produces structured and auditable JSON reports.
- Provides an agent interface that accepts CSV datasets and automatically evaluates candidate models.
- Focuses on transparent model selection and reproducible evaluation.

---

### [TechScope Search Engine](https://github.com/xxxxxxxx15339/TechScope-SearchEngine)

**Information Retrieval · Web Crawling · TF-IDF · Flask · Python**

A modular web-search and information-retrieval system.

- Performs parallel web crawling and HTML content extraction.
- Builds an inverted index for document retrieval.
- Implements TF-IDF query weighting and cosine-similarity ranking.
- Exposes search through a Flask web application.
- Collects runtime and performance telemetry.
- Serves as a foundation for BM25, semantic reranking and relevance evaluation.

### [MyOS](https://github.com/xxxxxxxx15339/MyOS)

**Operating Systems · C++17 · Scheduling · Memory Management**

A user-space simulation of essential operating-system components.

- Implements process and thread abstractions.
- Provides cooperative priority scheduling.
- Includes mutexes and blocking wait queues.
- Implements first-fit memory allocation and free-block coalescing.
- Includes a persistent inode-style file system.
- Provides an interactive shell for process and resource management.

### [Concurrent Reverse Proxy](https://github.com/xxxxxxxx15339/Reverse-Proxy)

**Go · Concurrency · Load Balancing · Distributed Systems**

A concurrent reverse proxy with dynamic backend management.

- Supports round-robin and least-connections load balancing.
- Performs periodic backend health checks.
- Provides a separate administration API.
- Uses thread-safe backend-pool operations.
- Demonstrates concurrent server programming in Go.

### [DouarMapper](https://github.com/xxxxxxxx15339/DouarMapper)

**Data Engineering · Record Linkage · Python · Excel Automation**

A data-cleaning tool for Moroccan commune and village datasets.

- Normalizes and cleans Excel records.
